# すて活クエスト MVP

片付けを「小さな冒険」に変える、7日間クエスト型のPWAプロトタイプです。

## 共有時の見せ方

仕事仲間には、次の観点で触ってもらうのがおすすめです。

- 続けたくなる体験になっているか
- 物を手放す心理ハードルが下がるか
- EXP、レベル、冒険ログが行動のきっかけになるか
- キャラクター、称号、武器の成長を感じられるか
- AI執事の言葉に、励ましや納得感があるか
- 「片付け」ではなく「人生の余白づくり」に感じられるか

## いま使えること

- 7日間クエスト
- 今日のクエスト達成
- アイテム名、写真、レア度、手放し方の登録
- EXP、レベル、連続達成、手放した数の記録
- マイ冒険者の称号変化
- 武器進化とステータス成長
- 冒険ログ
- 仕事仲間に送る共有文面
- スマホのホーム画面追加に向けたPWA設定
- オフライン表示用のService Worker

## データについて

このMVPの記録は、サーバーには送信されません。
ブラウザのローカル保存を使っているため、データは開いた端末の中だけに残ります。
